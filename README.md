# TucoTeca

Hub local para sua coleção de jogos, músicas e vídeos. Sem conta, sem nuvem.

## Instalação

### Windows
1. Baixe a release mais recente em https://github.com/Artur-Lucena/Projeto-Launcher/releases
2. Extraia o ZIP inteiro em uma pasta própria.
3. Abra `TucoTeca.bat`.

### macOS (Ventura 13.0+)
1. Baixe a release mais recente em https://github.com/Artur-Lucena/Projeto-Launcher/releases
2. Extraia o arquivo.
3. Dê duplo-clique em `Instalar-Mac.command` (1ª vez: clique direito > Abrir).
4. Abra `TucoTeca.app` em Aplicativos (1ª vez: clique direito > Abrir).

### Linux
1. Tenha Python 3.10+.
2. Execute `./BibliotecaHub.sh`.

## Executar pelos fontes
```
py -3.14 -m pip install -r codigo/ferramentas/requirements-ui.txt
py -3.14 codigo/frontends/desktop.py
```
